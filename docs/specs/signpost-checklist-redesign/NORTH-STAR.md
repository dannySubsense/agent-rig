# Sprint North Star: signpost-checklist-redesign
**Status**: Locked
**Date**: 2026-09-07

**Thesis** (Danny, 2026-09-07, approved verbatim): A check can only be trusted if it never has to
interpret what an agent meant — it can only reliably test words it forces the agent to reproduce
exactly, or content it can directly observe was really there. Any check that tries to infer
meaning from open language will eventually be gamed or will misfire, no matter how carefully it's
built — that was proven twice, not assumed, by the mechanism this one replaces.

**Objective** (Danny, 2026-09-07, approved verbatim): Make it impossible for an agent to silently
avoid disclosing that it hasn't verified something. Either the agent's claim of verification is
backed by something real and checkable, or the agent has to say plainly that it hasn't verified —
there's no third option where an evasion can hide.
