### Hook-mechanization cluster (DDR-005's instances), 2026-08-22

**Rollout policy (Danny, 2026-08-22, binding for this cluster):** ship one hook at a time. Each
gets a soak period before the next one starts — no parallel first-rollouts. Duration/exit
criterion for each soak period is "however quickly we can measure that hook's outcome," not a
fixed calendar window — decided per-hook when its Intake is written, not fixed here in advance.
Approved build order below is priority order for *starting Intake/build*, not a claim that all four
run concurrently.

**Exception, DDR-006 only (Danny, 2026-08-22):** real, current need from beta (blocking use), and
potential complementary value to other projects (DDR-010's adjacent shape). Decided: DDR-006 is
expedited, not parallel-deployed — it was already build-order 1st, so "run first" needed no
exception. What's actually granted: DDR-008's *spec/design* work (Intake, Interview, architecture)
may proceed in parallel with DDR-006's build, since that carries no runtime risk. **Live deployment
stays staggered** — DDR-008 does not go live until DDR-006 has soaked and its outcome is measured.
Paperwork parallelizes; production doesn't. This is a one-off exception for DDR-006's demonstrated
urgency, not a standing change to the cluster's rollout policy.
